# 演示指南

[返回项目首页](../README.md)

这份指南从观看与操作的角度介绍项目。各项内容可根据现场设备和演示版本组合，不要求所有扩展功能同时启用。

## 演示前准备

- 主机、显示器和手柄处于可用状态，显示器已切换到对应 HDMI 输入。
- 先确认首页显示和手柄基本操作，再进入具体演示场景。
- 语音相关环节需要配套语音设备与服务可用；网络条件不具备时，可先进行本地图形和手柄展示。

## 一、首页与应用选择

从统一首页开始，使用手柄浏览不同应用入口，再进入一个场景并返回首页。

**观察重点**：输入是否带来清楚的界面反馈，应用入口是否容易辨认，进出场景的操作是否连贯。

## 二、二维图形效果

展示填充、图像复制、图层叠加和透明效果。可以通过改变图层的显示顺序，观察同一区域的画面变化；也可以比较保留背景色和指定颜色透明后的视觉区别。

**观察重点**：画面内容是否完整，透明区域与重叠区域是否符合预期，图层变化是否容易理解。

## 三、手柄与游戏体验

选择一个交互场景，展示角色移动、射击、平台互动或角色战斗。支持双人互动的演示版本可安排两只手柄共同体验。

**观察重点**：角色动作与输入的对应关系、场景中的图形变化，以及从游戏返回首页的体验。

游戏内容用于展示主机的图形和交互能力。本仓库不提供游戏资源包或第三方素材下载。

## 四、语音交流与绘画

进入对应的语音或绘画应用，在配套服务可用时进行交流，并尝试简单的绘画请求，例如“画一朵花”。观察主机如何把请求结果呈现在屏幕上。

**观察重点**：从语音请求到画面反馈的完整过程，以及语音与屏幕内容的关联。

语音启动应用、游戏状态感知和事件触发陪玩属于持续拓展内容，是否安排在演示中以对应版本的联调状态为准。

## 展示范围

展示重点是作品的功能和交互体验。现场运行结果只对应当时的设备与版本，不据此推导其他版本或所有场景的表现。当前仓库不发布内部设计与性能测试数据。
