# Efinix Pixel Forge

**让 FPGA 图形能力走进可以玩、可以交流的交互式游戏主机。**

Efinix Pixel Forge 是一个以 FPGA 为基础的嵌入式游戏终端项目。项目围绕自研二维图形引擎，将画面输出、游戏运行、手柄操作和语音交互整合到同一台主机中，希望把底层图形能力转化为直观、可操作的演示体验。

本仓库是项目的赛事展示入口，介绍作品定位、功能和演示方式。

## 项目关注的问题

- **从图形功能走向完整体验**：不仅展示单个图形操作，也将其放入菜单、游戏和交互场景中。
- **让操作与画面形成反馈**：通过手柄控制角色、选择应用，并观察场景和界面的变化。
- **扩展游戏主机的交互方式**：在传统按键操作之外，探索语音交流和屏幕绘画。

## 功能与看点

| 方向 | 展示内容 |
| --- | --- |
| 二维图形 | 图像填充与复制、图层叠加、半透明混合和指定颜色透明效果 |
| 显示与界面 | HDMI 画面输出、统一首页、应用选择和场景切换 |
| 游戏体验 | 以射击、弹幕、平台互动和角色战斗等内容展示图形与输入的结合 |
| 手柄交互 | 无线手柄操作、角色控制、菜单选择，以及部分场景中的双人互动 |
| 语音与绘画 | 语音交流，以及将绘画指令呈现在主机屏幕上的交互体验 |
| 持续拓展 | 语音启动应用、游戏状态感知和事件触发陪玩等功能仍在联调与完善 |

上述内容涉及不同演示版本，具体组合以现场运行版本为准。开发中的扩展功能不等同于已经完成全部实机验收。

## 可以怎样体验

1. **从首页开始**：连接显示器，使用手柄浏览主机的应用入口。
2. **观察图形效果**：查看图像复制、图层叠加和透明效果，关注重叠区域如何变化。
3. **进入游戏场景**：通过角色移动、射击或平台互动，体验输入与画面的连续反馈。
4. **尝试语音绘画**：在配套服务可用的演示版本中，通过语音发出绘画请求，观察屏幕上的响应。

更详细的展示顺序与观察重点见 [演示指南](docs/DEMO.md)。

## 项目特点

**图形能力与应用场景一起展示。** 项目将图形效果放入实际界面和游戏内容中，让观看者能够通过操作理解它们的用途。

**手柄与语音各自承担适合的交互。** 手柄面向直接、连续的操作，语音用于交流和绘画等扩展体验。

**保留继续扩展的空间。** 围绕界面、游戏内容和交互方式持续迭代，逐步完善整机体验。

## 当前状态

项目处于赛事开发与展示准备阶段。现场演示包含图形、界面、手柄和语音相关内容；部分扩展功能仍需结合对应硬件、固件和配套服务进行联调。
